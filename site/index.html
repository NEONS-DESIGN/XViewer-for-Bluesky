Chrome / Brave / Edge 対応

Bluesky のメディアを、X のように見る。

プロフィールのメディアタブが、正方形のサムネイルを並べた格子に変わります。 画像を開けば右側に本文・投稿日時・反応数と返信の一覧が並び、そのまま画像や動画・GIF を付けた返信、リポスト・いいね・ブックマークまでできます。 画像そのものを押しても閉じないので、見ている途中で一覧へ戻されることもありません。

GitHub Releases からダウンロード GitHub で見る

ストアでの配布はまだありません。zip から読み込む手順は 導入 にあります。

一覧も、反応も、その場で

画像を 1 枚ずつ開いては戻り、投稿を確かめるたびに別の画面へ移る。その往復を減らすための拡張機能です。

メディアを格子で一覧

プロフィールのメディアタブを、正方形のサムネイルを 3 列に並べた格子に置き換えます。1 投稿につき 1 枚で、複数枚の投稿は先頭の画像にアイコンを付けます。動画はビデオタブに任せて並べません。下までスクロールすると続きを読み込みます。

投稿情報のパネル

画像を開くと、右側に作者・本文・投稿日時・反応数と「投稿を開く」が並び、その下に返信の一覧が新しい順に出ます。返信に付いた画像はサムネイルで並び、押すとその画像に切り替わります。返信の GIF・リンクカード・引用もカードで表示します。格子に限らず、Bluesky のどこで画像を開いても出ます。本文のリンク・メンション・ハッシュタグも押せます。パネルは畳めます。

開いたまま反応する

返信・リポスト・引用・いいね・ブックマークを、画像を閉じずに行えます。返信はパネルの入力欄から書いて送れ、画像を 10 枚まで、動画を 1 本、または GIF を 1 つ付けられます。本文に貼ったリンクはリンクカードに、投稿の URL は引用になります。「＋」で続きの投稿を足せば、10 件までの返信をスレッドとしてまとめて送れます。ALT 文・字幕・切り抜き・コンテンツの警告・投稿言語・絵文字も選べ、自分の返信は消すこともできます。いいねなどは押した瞬間に表示が変わり、失敗したときは元に戻して知らせます。認証は Bluesky 本体のものをそのまま使い、ログイン情報には触れません。

画像を押しても閉じない

画像そのものを押してもライトボックスを閉じず、押せるボタンの上でだけカーソルが指の形になります。周りの暗い部分を押せば今までどおり閉じます。閉じるボタンは左上に移し、画像オプションをその右に並べます。

タブを行き来するボタン

プロフィールの右下に「ビデオへ / メディアへ / 投稿へ / ページ先頭へ」のボタンを出します。今いるタブのボタンは隠れ、スクロールすると「ページ先頭へ」が出ます。ボタンの位置は変わらないので、同じ場所を押して往復できます。

ぼかしを外す (任意)

設定で有効にすると、格子のタイルに掛かる NSFW のぼかしと警告文を外し、1 回押すだけで開けるようにします。対象は格子のタイルだけで、Bluesky 本体が出す警告には触れません。既定ではオフです。

メディアタブを、見渡せる格子に

Bluesky の公開 API から取得した投稿をもとに、画像の付いた投稿を 1 枚ずつ正方形のタイルに並べます。 タイルを押すと Bluesky 本体のライトボックスで開くので、拡大や画像の送りは本体と同じ操作です。

  • 続きの取得は下までスクロールしたときだけです。先読みはしません
  • 別のアカウントへ移ると、前のアカウントの画像は残りません
  • ラベルの付いた画像は、本体と同じくぼかして表示します。(設定で外せます)
  • 投稿タブへ戻れば、いつもの Bluesky の表示に戻ります

画像の横に、投稿の中身を

パネルには作者・本文・投稿日時と、返信・リポスト・いいねの数が並びます。 その下のボタンから、画像を開いたまま反応できます。ボタンは種類ごとに色が付き、反応済みの投稿は最初から色が付いて表示されます。

  • リポストのボタンを押すとメニューが開き、リポストと引用を選べます
  • パネルの下には返信が新しい順に並び、「返信を表示」で返信への返信も開けます
  • 返信はパネルの入力欄からその場で送れます。リポストのボタンの「引用する」は、Bluesky 本体の投稿画面をライトボックスの上に開きます
  • 返信には画像を 10 枚まで付けられます (選ぶ・貼り付け・入力欄へのドロップ)。ALT 文・切り抜き・コンテンツの警告・投稿言語・絵文字も、Bluesky 本体の返信画面と同じように選べます
  • GIF は Bluesky 本体と同じ GIF 検索 (KLIPY) から選べます。本文に貼ったリンクはリンクカードに、Bluesky の投稿の URL は引用になり、本文のリンクは本体と同じく短い形で送ります
  • 動画は mp4・webm・mov・mpeg の 300MB・10 分までを 1 本付けられます。縮めずに元のファイルのまま送り、付けた時点でアップロードが始まります。進み具合が出て、処理が終わるまで送信できません。ALT 文と字幕 (.vtt を 1 本、20KB まで) は「字幕と ALT」の画面で付けます。画像・GIF とは同時に付けられず、引用とは一緒に送れます
  • 入力欄の「＋」で続きの投稿を足し、10 件までをまとめて送れます。添付とコンテンツの警告は投稿ごと、投稿言語は全体で 1 つです。ツールバーは書いている投稿の下に出て、2 件以上のときは「×」で投稿を消せます。途中の空の投稿は、聞いてから飛ばして送ります
  • 返信の一覧の動画はサムネイルのカードで出て、押すとその場で再生します。GIF の動画は音なしで流れます。再生できないときは「投稿で見る」から返信へ移れます
  • 返信の一覧の GIF は音なしで流れます。(OS の動きを減らす設定がオンなら、押したときだけ再生します) リンクカードは新しいタブで開き、引用は引用元の投稿へ移れます
  • ログインしていないときは、操作のボタンを出しません
  • 「投稿を開く」で、ページを再読み込みせずに投稿の画面へ移ります

拡張機能の設定は、ポップアップから

ツールバーのアイコンから開きます。メディアグリッド、ライトボックス、開発者向けの 3 つに分けて、機能ごとにスイッチでオンとオフを切り替えられます。

  • 変更は、ページを再読み込みせずにその場で反映されます
  • 関係する項目は親子にまとめてあり、親がオフの間は子を操作できません
  • ポップアップの配色はダークとライトを切り替えられます。既定は OS の設定に従います
  • 「設定を初期化」で、確認のうえすべての設定を既定に戻せます

導入

ストアでの配布はまだありません。GitHub Releases の zip を、ブラウザの拡張機能の画面から読み込んでください。

Chrome / Brave / Edge

  1. GitHub Releases から XViewer.for.Bluesky_版.zip をダウンロードして展開する
  2. chrome://extensions を開き、右上の「デベロッパーモード」をオンにする (Brave は brave://extensions、Edge は edge://extensions)
  3. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダを選ぶ
  4. 開いている bsky.app のタブを再読み込みする

新しい版にするとき

  1. 新しい版の zip を、前の版と同じフォルダへ上書きで展開する
  2. 拡張機能の画面で、XViewer for Bluesky のカードの再読み込みボタンを押す
  3. bsky.app のタブを再読み込みする

展開したフォルダを消すと、拡張機能も読み込めなくなります。消さずに置いておいてください。

Firefox (試験的)

  1. ソースを取得し、Node.js 24.2 以上で npm install と npm run build を走らせる
  2. about:debugging を開き、「この Firefox」を選ぶ
  3. 「一時的なアドオンを読み込む」で dist-firefox/manifest.json を選ぶ

一時的なアドオンは、Firefox を閉じると外れます。Firefox での動作はまだ十分に確かめていません。

設定でできること

すべてツールバーのポップアップから変更できます。字下げした項目は上の項目の子で、親の項目がオフの間は操作できません。(子の設定は保たれ、親をオンに戻すと元の状態に戻ります) 設定はブラウザの同期領域に保存され、外部には送信されません。(返信の入力欄で選んだ投稿言語だけは、このブラウザの中の保存領域に覚えます)

区分 項目 既定 効果
メディアグリッド メディアグリッド表示 オン プロフィールのメディアタブを、正方形のサムネイルの格子に置き換えます。オフにすると Bluesky 本体の表示に戻ります
メディアグリッド NSFW のぼかしを解除 オフ 格子のタイルに掛かるぼかしと警告文を外します。Bluesky 本体が出す警告には触れません
ライトボックス 投稿情報を表示 オン 画像を開いたとき、右側に本文・投稿日時・反応数を並べます。格子以外の画像でも動きます。画面の幅が狭いときは出しません
ライトボックス 返信・いいね オン パネルに返信・リポスト・引用・いいね・ブックマークのボタンを出します。オフにするとボタンだけが消え、パネルは残ります
ライトボックス 返信の一覧 オン 画像を開いたとき、パネルの下に返信の一覧を出します。「返信・いいね」もオンなら、その場で返信を書いたり (画像・動画・GIF・リンクカード・引用も付けられます)、自分の返信を消したりできます
ライトボックス 画像のクリックで閉じない オン 画像そのものを押しても閉じないようにし、押せるボタンだけにカーソルの形を残します。閉じるボタンを左上に移し、画像オプションをその右に並べます
開発者向け デバッグモード オフ タブの判定・格子の起動と撤去・取得の状況をブラウザのコンソールに出し、内部状態を html 要素の属性に書き出します。不具合を報告するときに使います

動作環境

Manifest V3 に対応した Chromium 系ブラウザで動作します。

対応ブラウザ

Chrome、Brave、Edge などの Chromium 系ブラウザ。Chrome 120 以上が必要です。Firefox (Firefox 140 以上) 向けにもビルドできますが、一時的なアドオンとしての読み込みで、動作はまだ十分に確かめていません。Safari には対応していません。

対象ページ

https://bsky.app/ のページ。格子とタブのボタンはプロフィールで、投稿情報のパネルとライトボックスの調整は bsky.app のどこで画像を開いても動きます。他のサイトや、スマートフォンのアプリでは動作しません。

対応言語

拡張機能の表示 (ポップアップ・パネル・ボタン) は今のところ日本語だけです。Bluesky 本体をどの言語で表示していても動作しますが、拡張機能が足した部分は日本語で表示されます。

不具合の報告・ご要望

バグの報告、ご質問、機能のリクエストは GitHub の Issues へお寄せください。不具合のときは、ポップアップの「デバッグモード」をオンにしてコンソールに出た内容を添えていただけると、原因を探しやすくなります。

データは、Bluesky の外へ出ません

この拡張機能には作者のサーバーがありません。通信するのは Bluesky の公開 API と、返信の一覧の読み込みやあなたが押した反応・返信 (添付した画像を含む) のために借りる Bluesky 本体の通信、それに返信の GIF とリンクカードのための Bluesky の中継サービス (gifs.bsky.app / cardyb.bsky.app) と GIF の配信元、返信の動画のための Bluesky の動画サービス (video.bsky.app) だけです。GIF の検索語とリンクの URL は、Bluesky 本体の返信画面と同じ送り先へ送ります。

収集しないもの

閲覧履歴、投稿やアカウントの ID、ログインのトークン、パスワード、個人情報。いずれも取得も保存も送信もしません。認証は Bluesky 本体のものを借りるだけで、トークンそのものには触れません。

保存するもの

あなたが選んだ 7 つのスイッチとポップアップの配色、投稿情報パネルを畳んだかどうか、それに返信の入力欄で選んだ投稿言語。どれもブラウザの中に留まり、外部サーバーへは出ません。

要求する権限

storage と https://public.api.bsky.app/* の 2 つだけ。スクリプトが動くのは bsky.app のページだけで、他のサイトへのアクセスは求めません。

プライバシーポリシーを読む

これは非公式の拡張機能です。

Bluesky Social PBC が作成・配布しているものではありません。 同社とは一切関係がなく、提携・支援・推奨を受けたものでもありません。

  • 利用は自己責任でお願いします。本拡張の利用によって生じた損害について、作者および Bluesky Social PBC は責任を負いません
  • いいね・リポスト・ブックマーク・返信は、押した分だけあなたのアカウントで Bluesky へ送られます。いいね・リポスト・返信は Bluesky 本体から操作したときと同じく公開されます
  • 返信は、パネルの入力欄であなたが「送信」か Ctrl+Enter (Mac は Cmd+Enter) を押したときだけ投稿されます。添付した画像と、リンクカード・GIF のサムネイル、字幕のファイルも、そのときにだけあなたのアカウントのサーバー (PDS) へアップロードされます。添付した動画だけは、付けた時点で Bluesky の動画サービス (video.bsky.app) へアップロードされます。(送信しなくてもアップロードされ、外すか入力欄を閉じると途中で止めます) リポストのボタンの「引用する」から開いた Bluesky 本体の投稿画面では、あなたが送信したときだけ投稿されます
  • 拡張機能から消せるのは、返信の一覧にある自分の返信だけで、「削除」に続けて「本当に削除？」を押したときに限ります。返信ではない投稿の作成や削除、フォロー、ブロック、DM の送信は拡張機能からは行いません
  • 画像を収集する機能はありません。ダウンロードも一括操作の自動化もなく、取得するのはいま見ているプロフィールの投稿だけです
  • Bluesky の仕様変更によって動作しなくなる場合があります
