プライバシーポリシー

最終更新日: 2026 年 10 月 18 日 / 制定日: 2026 年 10 月 18 日

この拡張機能は、いかなる個人情報も収集しません。

作者のサーバーはなく、Bluesky 以外へデータを送ることはありません。 保存するのは、あなたが選んだ設定だけです。以下はその詳細です。

1. 適用範囲

本ポリシーは、ブラウザ拡張機能「XViewer for Bluesky」(GitHub で配布しているもの。以下「本拡張機能」) および本サイト (xvbluesky.neonsdesign.com) に適用されます。

本拡張機能は、Bluesky (https://bsky.app/) のプロフィールのメディアをサムネイルの格子で表示し、画像のライトボックスに投稿情報と操作のボタンを加える非公式のツールです。 Bluesky Social PBC が作成・配布しているものではなく、同社とは一切関係がありません。 Bluesky 自体の個人情報の取り扱いについては、Bluesky のプライバシーポリシーをご確認ください。

2. 収集しない情報

本拡張機能は、以下のいずれの情報も収集しません。取得も、保存も、送信も行いません。

  • 個人を特定できる情報 — 氏名、住所、メールアドレス、年齢、個人識別番号など
  • 健康に関する情報
  • 財務状況や支払いに関する情報
  • 認証に関する情報 — パスワード、アプリパスワード、ログインのトークン、認証情報など
  • 個人的コミュニケーション — メール、DM など
  • 位置情報 — 地域、IP アドレス、GPS 座標など
  • ウェブ履歴 — 閲覧したページの一覧やその関連データ
  • ユーザーのアクティビティ — クリック、マウスの位置、スクロール、キー入力の記録など
  • ウェブサイトのコンテンツ — 画像、テキスト、音声、動画などの保存や外部への送信

本拡張機能は、Bluesky の投稿や画像を格子とパネルに表示するために読み込みますが、 それらは画面に描画するためにブラウザのメモリ上で扱われるだけです。 保存されることも、作者を含む第三者が取得できる場所へ送られることもありません。

3. 保存する情報

本拡張機能が保存するのは、ポップアップ画面で選んだ設定と、投稿情報パネルを畳んだかどうかだけです。 保存先はブラウザの設定同期領域 (chrome.storage.sync) で、 あなたのブラウザと、あなたがブラウザの同期を有効にしている場合はそのブラウザのアカウント (Chrome なら Google アカウント、Edge なら Microsoft アカウント、Firefox なら Mozilla アカウント) の中に置かれます。 作者を含む第三者がこれを読むことはできません。

保存される値は次の 8 件です。いずれも真偽値か、決められた選択肢の中の 1 つです。

  • メディアグリッドを表示するかどうか
  • NSFW のぼかしを解除するかどうか
  • 投稿情報パネルを表示するかどうか
  • パネルに返信・いいねのボタンを出すかどうか
  • 画像のクリックでライトボックスを閉じないようにするかどうか
  • デバッグモードを使うかどうか
  • 設定画面の配色 (OS に従う / ダーク / ライト)
  • 投稿情報パネルを畳んでいるかどうか

閲覧した投稿やアカウントの ID、閲覧の履歴、いいねやリポストの記録は、一切保存しません。

デバッグモードを有効にしたときは、拡張機能の内部の状態 (今のタブ、格子が動いているかどうか、取得した件数など) を ブラウザのコンソールと、開いているページの html 要素の属性に書き出します。 これはそのページの中だけにあり、保存も送信もされません。ページを閉じれば消えます。

保存した情報の削除

設定画面の「設定を初期化」を押すと、保存した値は既定に戻ります。 ブラウザから本拡張機能を削除すると、保存領域ごと削除されます。

4. 通信先

本拡張機能はサーバーを持ちません。作者が管理するサーバーへの通信は一切発生しません。 本拡張機能が自分で通信するのは、Bluesky の公開 API だけです。

  • https://public.api.bsky.app/ — 表示しているプロフィールの情報と投稿の一覧、ライトボックスで開いた投稿の情報の取得。ログインを必要としない公開の API です

格子のサムネイルは、Bluesky が投稿に付けている画像の URL (Bluesky の画像配信用サーバー) をそのまま表示しています。 Bluesky を通常のブラウザで閲覧したときと同じ読み込みです。

パネルからいいね・リポスト・ブックマークを押したときは、Bluesky 本体がページの中に持っているログイン済みの通信の仕組みを借りて、 あなたのアカウントのデータを置いているサーバー (PDS) へ送ります。宛先の決め方とトークンの扱いは Bluesky 本体に任せており、 本拡張機能はトークンを読みません。Bluesky のボタンを押したときと同じ通信です。 返信と引用は Bluesky 本体の投稿画面を開くだけで、投稿するのはあなたが送信したときの Bluesky 本体です。

アクセス解析、広告、クラッシュレポートの類は一切組み込んでいません。

5. 要求する権限とその理由

本拡張機能が要求する権限は次の 2 つだけです。スクリプトが動くのは bsky.app のページだけで、他のサイトへのアクセスは求めません。

storage

前述の設定を保存するために使用します。設定はツールバーのポップアップで変更し、 Bluesky のページで動くスクリプトが読み取るため、この 2 つをまたいで値を共有する手段が必要です。

https://public.api.bsky.app/*

Bluesky の公開 API から、プロフィールの投稿の一覧と、開いた投稿の情報を取得するための権限です。 この 1 つのドメインに限定しています。

6. ログイン情報の扱い

本拡張機能は、Bluesky のログインのトークンやパスワードを読み取りません。 Bluesky はログインの情報をブラウザの保存領域に置いていますが、本拡張機能はそこに触れません。

いいね・リポスト・ブックマークの送信には、Bluesky 本体がページの中に持っているログイン済みの通信の仕組みを借ります。 そのとき読むのは、自分のアカウントの識別子 (DID) だけです。これは、自分のいいねやリポストを自分のアカウントに記録するための宛先として使い、保存も外部への送信もしません。 借りた仕組みで行えるのは、自分のいいね・リポスト・ブックマークの付け外しと、投稿の情報の取得だけに限ってあります。 投稿の作成や削除、フォロー、ブロック、DM の送信はできないようにしてあります。

これらの操作は、あなたがパネルのボタンを押したときにだけ実行されます。自動的に送信されることはありません。

7. 第三者への提供

収集する情報がないため、第三者に提供する情報もありません。 本拡張機能は、利用者のデータを販売、譲渡、共有することはありません。 また、単一の用途 (Bluesky のメディアの表示とライトボックスの使い勝手を良くすること) と無関係な目的で データを使用することはありません。信用力の判断や融資の目的で使用することもありません。

8. 本サイトについて

本サイトは GitHub Pages (GitHub, Inc.) 上で公開している静的なページです。 アクセス解析、広告、外部のフォント、外部のスクリプトは一切使用していません。 本サイトが Cookie を設定することもありません。 配色の切り替えを選んだときだけ、その選択をあなたのブラウザの保存領域 (localStorage) に覚えます。

ただし、ホスティング事業者である GitHub, Inc. が、サービスの提供に伴ってアクセスログ (IP アドレスなど) を記録する場合があります。これは作者が管理するものではありません。 詳細は GitHub 社のプライバシーに関する声明をご確認ください。

なお、本サイトに掲載しているスクリーンショットは、Bluesky 公式アカウント (@bsky.app) の公開プロフィールを、 本拡張機能を入れたブラウザで実際に表示した画面です。投稿・画像・反応数には手を加えていません。 撮影に使ったアカウントのアイコンと、共通のフォロー中の表示だけは隠しています。

9. 子どもの利用について

本拡張機能は、いかなる利用者からも個人情報を収集しません。年齢を問わず、これは変わりません。 なお、NSFW のぼかしの解除は既定ではオフで、対象は本拡張機能が表示する格子のタイルだけです。 Bluesky 本体のコンテンツの表示設定や、Bluesky が出す警告を変えることはありません。

10. 本ポリシーの変更

本ポリシーを変更する場合は、このページを更新し、冒頭の最終更新日を改めます。 重要な変更を行う場合は、GitHub Releases の更新情報でもお知らせします。

11. お問い合わせ

本ポリシーおよび本拡張機能についてのお問い合わせ、不具合の報告、ご質問、ご要望は、以下からお願いします。

  • GitHub の Issues: Issues を開く (GitHub のアカウントが必要です)

GitHub の Issues に書いた内容は、誰でも読める公開の場に載ります。個人情報は書き込まないでください。 デバッグモードの出力を貼るときも、ご自身のアカウントの識別子などが含まれていないかを確かめてから貼ってください。
